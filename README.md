# FrameModelMaker-Web

**Version 1.2.0**

新機能の操作・交換規約・容量制約は[1.2リリースガイド](docs/RELEASE_1_2.md)を参照してください。CSV入力、貼り付けプレビュー、配列複製、プリセット、局所軸表示、復旧センターを追加しました。2026-10-15 のコンピューターユース評価で挙がった修正（荷重ケース編集対象の同期、数量の自動再集計、断面計算の状態表示、小数入力、通知の種別化、作図の数値入力、結果数値表など）は[対応記録](docs/CUA_REVIEW_2026-10-15.md)を参照してください。

FrameModelMaker-Web は、立体フレーム解析モデルをブラウザ上で作成・検証・可視化し、JSON / YAML で受け渡すための TypeScript アプリケーションです。インストール不要で、節点・部材・断面・材料・境界条件・バネ・壁・荷重を表形式と 3D ビューから編集できます。

> C# Windows Forms アプリケーション「Abi-FrameTerminal」のモデル編集機能を、Web 向けに再設計したプロジェクトです。本アプリ自身は FEM 解析を実行しません。

## 主な機能

- モデル診断基盤: 重複番号、参照切れ、ゼロ長部材、不正な物性・荷重配列などを ERROR / WARN / INFO で診断
- 編集履歴: Undo / Redo、未保存表示、復旧用スナップショット、参照追従付き再採番、重複節点統合
- 連携選択: 3D の節点・部材・壁とデータグリッドを双方向に選択
- 表編集グリッド: 数値・列挙・参照等の型付きセル、複数行選択、検索、表示ソート、TSV コピー＆ペースト、CSV 出力
- 3D / 2D 表示: 標準視点、透視 / 平行投影、9レイヤー、番号、色分け・凡例、平面/立面での作図・移動・複製
- 荷重・境界条件表示: 節点荷重と6自由度境界条件の 3D グリフ表示。部材荷重表示は実験的です
- 荷重ケース: 名前・種別・メモ、追加・複製・削除。荷重組合せはケース選択＋係数の表で作成・編集・複製
- ファイル交換: バージョン付き JSON、旧 JSON の移行、strict / lenient 読込、解析用 YAML の診断付き入出力
- 断面・数量: 代表断面の断面性能計算とモデル統計・数量集計の基盤
- 解析結果ビュー（実験的）: 外部 JSON の変位・反力・部材端力を読み込み、変形表示と時刻歴アニメーション。選択要素の数値、最大・最小値、フレーム CSV 出力
- 状態通知: ステータスバーは成功／エラー／取消を `data-kind` と連番で区別し、古い通知が残りません
- 日本語 / 英語、ダーク / ライトテーマ、キーボード操作、レスポンシブレイアウト

## 基本操作

### ファイル

- **新規作成**: 空のドキュメントへ切り替えます。未保存変更がある場合は確認します。
- **開く**: `.json`、`.yaml`、`.yml` を読み込みます。入力サイズの上限は 100 MiB です。
- **保存**: 現在の作業モデルを JSON v2 で保存します。検証エラーは診断で確認できます。
- **YAML 出力**: YAML 由来の解析メタデータを可能な範囲で保持して再出力し、表現できない項目を警告します。
- **CSV 出力**: 現在のタブを表形式で出力します。
- **サンプル読込**: 同梱モデルを読み込みます。

読み込みは一時ドキュメントで完了してから置換されます。未知の将来 JSON バージョンや不正ファイルで、編集中のモデルを部分的に上書きしません。

復旧センターからIndexedDBの候補を復元・削除できます。編集タブごとに分離して保存し、保存中・成功・失敗を表示します。旧localStorageデータは検証後に移行します。ブラウザの保存容量には上限があるため、JSONファイルも保存してください。

### データ編集

右側のタブで、節点、部材、断面、材料、境界条件、バネ、壁、節点荷重、部材荷重、CMQ 荷重を編集します。

- 行クリックで選択、`Ctrl` / `Shift` で複数選択
- 検索欄で表示行を絞り込み
- `Ctrl+C` / `Ctrl+V` で選択範囲を TSV としてコピー＆ペースト
- 参照列は存在する番号から選択
- 番号変更、再採番、節点統合は参照先も同一操作で更新
- `Ctrl+Z` / `Ctrl+Y` で Undo / Redo。セルを確定した後（Enter / Tab）にセルへフォーカスしたままでもモデルの Undo / Redo が効き、文字入力中はテキストの取り消しになります
- `Delete` で選択行を削除。参照中の要素は安全確認の対象
- 列ヘッダーのツールチップに列の意味・単位・正方向・例を表示
- 検索欄の絞り込み状態（検索語と表示件数）をツールバー下に表示。新規作成・読込で検索語は初期化
- タブは左右スクロールボタンとタブ一覧セレクトから選択でき、「表を最大化」「ビューを最大化」で片方を隠せます

荷重タブは上部の荷重ケース選択と連動します。荷重ケースは最低 1 件を維持し、ケース ID を使って荷重組合せと関連付けます。荷重組合せパネルは編集対象（表示番号・名前・固定 ID）を表示し、ケースを切り替えると入力を同期します。未確定の編集がある場合は保存・破棄・取消を選べます。

### 3D ビュー

| 操作 | 動作 |
|---|---|
| 左ドラッグ | 回転 |
| 右ドラッグ | 平行移動 |
| ホイール | ズーム |
| 要素クリック | 節点・部材・壁を選択 |
| キャンバス上の矢印キー | キーボード照準を移動 |
| キャンバス上の `Enter` | 照準位置で選択または作図を確定 |
| `F` | モデル全体を表示 |
| `Esc` | 選択または作図モードを解除 |

ツールバーから上面・正面・側面・アイソメ、透視 / 平行投影、2D 平面・X/Y立面、節点・部材作図、選択要素の移動・オフセット複製、荷重、解析結果を切り替えられます。作図・移動・複製モードでは「作図設定」パネルでスナップ間隔・ON/OFF、作業平面位置、絶対／相対座標の数値確定ができ、現在座標とスナップ先の節点番号をテキストで表示します。番号と境界条件の表示は「表示」メニュー、全レイヤー・選択のみ表示・色分け・凡例（材料番号を常に併記）・ラベル密度は「モデル情報」から変更できます。番号ラベルは背景付きで拘束記号や荷重文字と重なっても判読できます。浮動パネルは折り畳み・ドッキング・サイズ変更ができ、選択情報パネルの「×」はパネルを閉じるだけで、「選択解除」で選択を解除します。非操作時は再描画を停止します。部材・壁の移動は構成節点を移動するため、共有節点に接続する他要素も追従します。

### 検証とツール

- **モデル検証**: 診断の重要度、コード、対象番号、説明を表示
- **モデル情報**: 要素件数、部材総延長・体積、孤立節点を表示し、開いたままでもモデル変更に追従して再集計（2万要素超は「更新待ち」と再集計ボタン）。断面別数量 CSV（`totalLength_cm` / `volume_cm3`）は出力時に最新モデルから計算
- **断面計算**: 矩形、円形、箱形、H 形の寸法から `A / J / Iy / Iz / ky / kz` を単位付きで算定。入力変更後は「前回計算値」、失敗時は旧値を破棄して表示。適用先は断面の追加・削除・番号変更に追従し、未選択では適用不可
- **インポートレポート**: 読込前プレビューで件数・単位・診断を確認し、YAML 読込後に単位変換、スキップ要素、保持・欠落情報を確認。診断は JSON / CSV / Markdown で保存
- **YAML 出力前の確認**: 要素数・出力単位・欠落項目（壁、カスタム端バネ、節点／部材／CMQ 荷重値）を表で表示
- **解析結果（実験的）**: 検証済みの外部解析結果 JSON を読み込み、変形・反力・断面力の表示と倍率、フレーム／時刻の直接入力、前後・先頭／末尾、再生速度・ループを操作。ファイル名・結果名・再生状態・フレーム数を表示し、モデル編集時は古い結果を自動的に破棄して表示も同期。選択節点・部材の数値、最大・最小値と位置、現在フレームの CSV 出力
- **プリセット**: ビュー・断面テンプレートを検索・名前変更・上書き・複製・削除（取り消し可）し、適用内容を通知

## ファイル形式

### Frame JSON v2

保存 JSON には `formatVersion: 2` が必ず付きます。バージョンなしの従来ファイルは v1 として移行されます。v2 では、従来のモデル要素に加えて次を保持します。

- 安定 ID を持つ `loadCases`
- `loadCombinations`
- YAML 解析情報を保持する `analysisMetadata`
- 断面の正式なねじり定数 `torsionConstant`。旧 `p2_Ix` は互換フィールドとして保持

`parseFrameJson()` は `strict` と `lenient` を選べます。strict はパーサーが検出した型違反を拒否し、lenient は補正内容を診断として返します。画面からのJSON読込はstrictを先に試し、旧ツールや手編集ファイルの型違反だけを診断付きlenient読込へフォールバックします。未知の将来バージョンは拒否します。JSON Schema による完全検証ではないため、読込後と検証済み出力前にはモデル診断も実行してください。

### 解析用 YAML

`schema_version: "1"`、`units`、`model` を持つ YAML を扱います。入力単位 `mm / N` 系は内部の `cm / kN` 系へ変換されます。節点、支持、材料、断面、主要線材に加え、荷重ケース・荷重組合せと次の情報を `analysisMetadata` に保持します。

- `equalDOF` 制約
- 節点質量
- `twoNodeLink3D` の剛性・方向
- グループ、抽出指定、元タグなどのトレーサビリティ

非対応・簡略化・スキップした要素は診断へ記録されます。再出力は節点、支持、材料、断面、線材、解析メタデータ、荷重ケース・組合せに対応します。現行解析 YAML スキーマで表現できない壁、部材端バネ、FrameModelMaker 固有の節点 / 部材 / CMQ 荷重は出力診断で警告します。YAML の全スキーマを損失なく往復できることを保証するものではありません。

### 解析結果 JSON v1

解析結果はモデル JSON と別ファイルです。`formatVersion: 1`、任意の `loadCaseId` / `combinationId`、時刻順の `frames` を持ちます。各フレームには節点変位・回転・反力と、部材 I/J 端力を格納できます。静的な単一フレーム形式も読み込めます。

> **実験的機能:** v1 は `units.length = "cm"`、`units.force = "kN"`、`units.moment = "kN-cm"`、`coordinateSystem = "global-xyz"`、`nodeReactionSystem = "global-xyz"`、`memberForceSystem = "local-xyz"` を必須とします。欠落・不一致、現在のモデルにない節点・部材・荷重ケース・組合せの参照は読込時に拒否し、汎用結果パーサーは単位・座標・符号を変換しません。OpenSees専用アダプターは対応規約を検証して単位・端力符号を変換します。モデル編集時は読み込み済みの結果を破棄します。外部結果はこの規約へ変換・検証してから読み込んでください。断面力図は確認用の実験的表現であり、この表示だけを構造安全性の判定に使用しないでください。

## 単位系と座標系

| 種別 | 内部単位 |
|---|---|
| 長さ | cm |
| 力 | kN |
| モーメント | kN·cm |
| 応力度・弾性係数 | kN/cm² |
| 断面積 | cm² |
| 断面二次モーメント・ねじり定数 | cm⁴ |

座標系は X = 水平右、Y = 水平奥、Z = 鉛直上です。外部形式との単位・局所軸・符号規約は、インポート診断と [技術仕様書](docs/SPECIFICATION.md) を確認してください。

## 実装上の制約

- FEM ソルバーは含みません。解析結果は外部ソルバーから読み込みます。
- 復旧はIndexedDBの容量・ブラウザーの保存方針に依存します。履歴は最大100件・64MiBを目安に削減し、現在のチェックポイントを保持します。差分履歴は採用していません。
- YAML 再出力は保持できた情報を対象とするベストエフォートです。
- 壁厚の正式仕様がないため、壁体積・重量は数量集計の対象外です。
- `Material.unitLoad` の意味を指定しない限り、材料重量は確定値として扱いません。
- 200行超のグリッドは仮想化し、大きな読込はWeb Workerで処理します。モデル適用・編集・Undo・書出しには全体処理が残ります。[性能測定](docs/PERFORMANCE.md)を参照してください。
- 結果JSONの正規形式は固定単位です。OpenSeesの3D弾性梁用アダプター、モデル指紋、局所軸照合、中間断面力点に対応します。指紋のない旧結果は同番号の別モデルを識別できません。

## プロジェクト構成

```text
src/
  app/          ダイアログ、ツールパネル、ファイル出力
  io/           JSON v2・解析 YAML の入出力
  models/       フレームモデル、荷重ケース、解析メタデータ・結果
  services/     履歴、断面性能、モデル統計
  validation/   モデル健全性検証
  ui/           型付きデータグリッドとクリップボード処理
  viewer/       Three.js ビューア、2D 作図、結果表示
tests/          モデル、IO、サービス、UI、ビューアのテスト
docs/           技術仕様と設計監査
```

詳細は [技術仕様書](docs/SPECIFICATION.md) と [追加機能提案・実装記録](docs/FEATURE_RECOMMENDATIONS.md) を参照してください。
